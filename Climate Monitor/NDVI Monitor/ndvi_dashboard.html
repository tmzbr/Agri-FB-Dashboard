Source: NASA MODIS MOD13Q1 / MYD13Q1 v6.1 (Terra + Aqua, 250 m, 16-day composites; the two satellites are offset by 8 days, so there is a new value every 8 days), averaged over each municipality polygon (IBGE). Only good / marginal pixels enter the average (cloud, snow and shadow are dropped); a municipality-window with 25% or fewer usable pixels is left out. Observed data only: each point is a composite window dated by its mid-point (start + 8 days). Monthly = average of the windows centred in that month; for the month in progress, earlier years are averaged over the same windows already observed this year, so the comparison is like-for-like. State groups (RS · PR · MS · MT · GO · MATOPIBA): each region row is averaged over every municipality it contains — switch Rows to Municipalities to see each one; the three ▣ state-average rows weight the regions by municipality count, corn output or soybean output (2022–24 avg), as in the Weather Monitor. Farms show the NDVI of the municipality where they sit (a municipal average — not the farm's own fields). NDVI near 0.2 = bare soil · 0.5 = developing crop · 0.8+ = dense canopy.
